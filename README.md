# Schemaestro

On-brand designs from a brief, in your AI assistant: launch posts, quote cards, calls to action and other
animated posts, laid out by code from typed design schemas (not drawn by an AI model).

- **Connect:** add `https://schemaestro.com/mcp` as a connector in Claude or ChatGPT. No sign-in.
- **Edit and export:** every design has an EDIT button and a link that opens it on schemaestro.com,
  where you can change the words and export MP4 or GIF on your own device.
- **Privacy:** https://schemaestro.com/privacy

## Support

Something not working, or have an idea? [Open an issue](https://github.com/schemaestro/schemaestro/issues)
